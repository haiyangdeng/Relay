# Artwork and asset provenance

## Existing squirrel artwork provenance

The application source currently retains the user's existing Relay squirrel branding. The available development record confirms that the rounded app-icon variant was created by editing an existing squirrel image with an image-generation tool; the menu-bar SVG retained the existing squirrel paths and added a status dot. That record does **not** identify the first image/path creator or establish the original asset's redistribution terms.

The V1.0.0 publication retains the existing user-supplied branding at the maintainer’s request. Its original creator and redistribution terms are still not documented; the maintainer should supplement that record or replace the asset with artwork whose origin is documented. This is a missing provenance record, not a determination of infringement. The publication process has not declared the artwork to be covered by the GPL.

Affected application assets:

- `src/renderer/src/assets/relay-icon.png` — in-app squirrel image.
- `src/renderer/src/assets/relay-mascot-transparent.png` — generated transparent hero variant.
- `build/relay-app-icon-source.png` — rounded app-icon source.
- `build/relay-1024.png`, `build/relay.iconset/`, `build/relay.icns` — derived macOS app icons.
- `resources/relay-tray.svg` and `resources/relay-tray-*.png` — squirrel menu-bar variants and state dots.
- `scripts/relay/build-tray-icons.swift` — retained squirrel path geometry used to generate the menu-bar assets.

`site/` presents the actual Relay app icon and real application screenshots supplied for V1.0.0 publication. Screenshot and icon inclusion does not create a new license for the existing squirrel artwork. The old hand-drawn interface illustration is no longer used. Screenshots document the captured application UI; they are not evidence that every network or uninstall scenario has passed live validation.

## Inherited upstream assets

Legacy `resources/icon*`, `resources/subStoreIcon.png` and embedded fallback icons originate from the inherited Clash Party source tree. They are retained where the existing source imports require them. Their presence is not a claim of ownership of the upstream name or marks. Relay's public product presentation must use Relay branding and retain the upstream attribution in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Support payment image

`site/assets/support-alipay.png` is the maintainer-supplied Alipay payment image, explicitly provided for public display in the README and introduction website. Both pages reference the same unmodified file. Its payment code and embedded avatar are not application artwork and are not covered by the project's source-code license.

## Test assets

The two `.mmdb` files under `scripts/relay/fixtures/assets/` are official artificial test data from a fixed MaxMind DB commit. The source links and hashes are in that directory's `manifest.json`; the MIT license option and copyright notice are retained at [licenses/MaxMind-DB-MIT.txt](licenses/MaxMind-DB-MIT.txt). They contain no imported personal proxy or subscription configuration.

## Build-generated assets

Native executables, app packages, installer packages, signing material and downloaded core binaries are excluded from the Git source tree. Build-generated resources should be reproduced from the documented scripts and pinned manifests; they are not substitutes for their corresponding source and notices.

## 2026-11-12 visual refinement

The built-in image generation tool produced the transparent overview mascot and enlarged Dock icon from the existing Relay artwork. It did not establish the original artwork's redistribution rights. Both edits retain the existing character; the macOS Dock source reduces empty outer padding. Icon resolution variants are generated by `scripts/relay/build-app-icon.zsh`.

The menu-bar variant is an editable, reverse-color rounded tile with the existing squirrel cut out and a separate status dot. The Swift generator rasterizes the SVG directly at output resolution, without a low-resolution SVG mask. Built-in icons render at 18 pt with six scale representations; custom user icons retain their previous 16 pt scale.

Dock edit prompt (built-in tool):

> Use case: precise-object-edit. Edit this existing Relay macOS app icon only by enlarging the rounded-square tile and its squirrel together to occupy 90% of the square canvas width and height, centered, leaving only 5% transparent outer padding on each side. Current tile has excessive outer transparent margins and appears too small in the Dock. Keep the existing squirrel identity, proportions, ears, face, eyes, flying pose, periwinkle and cream colors, navy rounded-square background, and overall artwork exactly as close to original as possible. The squirrel should remain large and recognizable within the navy tile, with all extremities visible. True transparent pixels outside the tile, crisp smooth silhouette, no text, no extra objects, no white border, no backdrop outside the rounded tile. Output a single square macOS icon asset.

Hero cutout prompt (built-in tool, source `src/renderer/src/assets/relay-icon.png`, transparent background enabled):

> Use case: background-extraction. Edit target: supplied Relay squirrel app icon. Create a clean transparent-background PNG cutout of only this exact lavender-blue and cream flying squirrel. Change only the background: remove the dark navy square background, including the gaps between its tail, arms and body. Preserve the squirrel's identity, facial expression, silhouette, pose, proportions, lavender-blue and cream palette, and clean illustration style exactly. Center the complete squirrel with a small even transparent margin; do not crop ears, arms, feet or tail. Actual alpha transparency, not a checkerboard picture. No text, no badge, no square plate, no border, no extra objects or shadow background. This will sit above a separately drawn blue curved background in the Relay desktop app hero.

## 2026-11-15 application icon size

The built-in image editing tool reduced the transparent outer margin of the existing rounded app icon. Both Intel and Apple Silicon packages use the same regenerated `build/relay.icns`; `site/assets/app-icon.png` mirrors the generated 1024 px icon. In-app artwork and menu-bar icons are unchanged.

Edit prompt: enlarge the existing navy tile and squirrel together to occupy 93% of a square canvas, centered, with a transparent exterior. Preserve the character, pose, internal proportions, colors and gradients; add no text, border or objects, and do not crop the tile.
